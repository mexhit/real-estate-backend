# Decision Provider (JEV) is a separate interface from AI Provider, not a fourth AI Provider setting value

JEV does not generate text: it takes a state and typed questions and returns a probability. It therefore cannot implement `AiProvider.generateText`, and we did not force it into the `AiProviderType` setting alongside `GEMINI`, `GEMINI_2` and `GROQ`. Instead `JevAiProviderService` implements a separate `DecisionProvider` interface and is injected into `PropertyMetadataExtractionService` through its own `DECISION_PROVIDER` token, next to `AI_PROVIDER`. It is always JEV and is not selectable at runtime, so a JEV failure never affects metadata extraction. The alternative — a shared text-in/text-out abstraction with JEV adapting a prompt into a question — would have hidden what makes JEV useful (the calibrated probability) and tied extraction to a vendor that cannot do it. If a second Decision Provider is ever needed, add a setting and a resolver then, mirroring `AiProviderResolver`.
